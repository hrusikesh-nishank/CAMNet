
# Sample Results (PDF)

This folder contains a small set of qualitative examples exported as PDF pages for easy viewing.

## Organization

Samples are grouped by dataset:

- `lol/`
- `fivek/`
- `velol_l_subset/`
- `loli_street_subset/`
- `loli_street_subset/` examples are split by scene/filename.

Each PDF typically contains a triplet comparison (Low / Ground Truth / Enhanced) and may include PSNR/SSIM annotations depending on how it was exported.

## Notes

- Only a limited number of examples are included to keep the repository lightweight.
- Full datasets are not hosted here. Use the download link in `data/README.md`.
- Dataset references are listed in `data/README.md`.
